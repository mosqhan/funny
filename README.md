## 블랙홀 3D 시뮬레이션 (`blackhole.html`)

외부 라이브러리 없이 순수 WebGL로 작성된 단일 HTML 파일입니다. 브라우저에서 바로 열면 됩니다.

- **시점 조작**: 마우스 드래그로 회전, 휠 또는 핀치로 확대·축소, 더블클릭으로 초기화
- **중력 렌즈**: 슈바르츠실트 시공간의 광선 측지선을 픽셀마다 수치 적분해 블랙홀 그림자, 광자 고리, 뒤쪽 원반이 위아래로 감싸 보이는 왜곡을 표현
- **강착원반**: 케플러 회전과 안쪽으로 흘러드는 난류 패턴, 도플러 빔 효과, 중력 적색편이
- **빨려드는 물질**: 원반 안에서 나선 낙하하는 입자와 외부에서 흘러들어 원반에 정렬되는 기체 흐름
- **배경**: 절차적으로 생성된 별, 은하수, 외부 나선은하 (모두 렌즈 효과의 영향을 받음)
